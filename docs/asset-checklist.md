# Asset Checklist (human capture required)

These screenshots and GIFs **cannot be generated by an AI** — they must be captured by a
human running the addon in-game and the sim on the live site. Follow the framing rules in
[`visual-identity.md`](visual-identity.md). Save every file to the path listed below.

Target folder: `docs/assets/` (created — see `.gitkeep`).

## In-game (addon)

- [ ] **Live tank readout** — `/tgs` open on the Live tab, on a real geared tankadin.
  Show uncrittable ✓ + surplus, avoidance breakdown, uncrushable status + crush surplus,
  armor DR, physical EHP, spell power, block value. Have "Assume Holy Shield" and "Assume
  Kings+MotW" toggles visible.
  → `docs/assets/addon-live-readout.png`

- [ ] **Optimize tab with sliders** — the in-game Optimize tab showing the four tuned
  sets (Raid Threat / Survival / AOE Trash / Balanced) and the per-goal EHP↔Threat and
  Min-HP sliders. Capture after a solve so real results are on screen.
  → `docs/assets/addon-optimize-tab.png`

- [ ] **Minimap flyout equipping a set** *(GIF)* — click the minimap button, show the
  ItemRack-style flyout of sets, hover to preview, then click to equip. A few seconds,
  loops cleanly.
  → `docs/assets/addon-minimap-flyout.gif`
  *(Optional companion still:* `docs/assets/addon-minimap-flyout.png` *)*

- [ ] **Export tab** — `/tgs export` showing the copy box + SavedVariables flush hint,
  for the "export to website" step of the funnel.
  → `docs/assets/addon-export-tab.png`

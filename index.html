How to get your export
  1. Install the TankadinGearSim addon, /reload.
  2. Open your bank (so banked gear is included), then run /tgs.
  3. Either copy the text from the box, or run /reload and grab the file WTF/Account/<acct>/SavedVariables/TankadinGearSim.lua.
  4. Paste the text below, or upload the .lua file. Both work.
